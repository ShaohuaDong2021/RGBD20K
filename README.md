# RGBD20K

**RGBD20K: A Large-Scale RGB-D Dataset for Robust and Efficient Visual Perception**

This repository provides the dataset, pretrained models, re-annotated SUN RGB-D dataset, and implementation associated with **RGBD20K**.

---

## 📦 Dataset

The **RGBD20K dataset** is available through Google Drive:

👉 **[Download RGBD20K Dataset](https://drive.google.com/drive/u/2/folders/1bCeuH562P_EJU8msNMMifu2wylbruWBO?dmr=1&ec=wgc-drive-%5Bmodule%5D-goto)**

Please refer to our paper for detailed information about dataset construction, annotation, data splits, and benchmark protocols.

## 💻 Code

The implementation will be released in this repository.

The code is organized based on our previous open-source projects and related multimodal RGB-D implementations:

* **[EGFNet](https://github.com/ShaohuaDong2021/EGFNet)** — our previous RGB-T scene parsing project.
* **[GeminiFusion](https://github.com/JiaDingCN/GeminiFusion)** — an open-source implementation for multimodal RGB-D semantic segmentation.

The RGBD20K implementation will include:

* Training and evaluation code
* Dataset preparation
* Configuration files
* Model definitions
* Pretrained model loading
* Benchmark evaluation
* Inference scripts

Detailed installation, training, and evaluation instructions will be provided once the code is released.
